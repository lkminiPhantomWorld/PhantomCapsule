## 可變形檔案
同一個唯一 Identity，可依輸入來源、輸出目的、顯示能力、App 契約、任務情境、互動方式與授權條件，顯影成不同可讀、可看、可聽、可互動、可執行的 Projection；所有合法變更再吸回同一個既有正式本體。

## 正式閉環
任意可讀來源
→ 經🥳歡迎光臨唯一路口讀取
→ 抽取內容、資料、功能、狀態、關係、樣式與互動
→ 判定唯一 Identity
→ 完全相同內容只留下來源證據
→ 同一 Identity 的新內容與能力吸回既有本體
→ 不同格式掛為合法 Projection
→ 依輸出端可承受能力選擇顯影
→ 有實體形式時產生實體 Projection
→ 尚無實體形式時建立抽象出口契約
→ 使用者或機器互動
→ 驗證權限與變更
→ 合法變更裝回同一本體
→ 更新 State、Lineage、Manifest、SHA256、Snapshot 與 ReverseChain
→ 留下可觀測變更痕跡
